# CoWiki 第一個內置插件：Daily Notes

**使用方式。** 本次只把日記改為插件。首次打開已有本地 Space，沿用既有 Today 開關、文件夾、日期格式和模板；同一天再次點 Today 打開同一份 Markdown。關閉插件只移除入口和啟動行為，不刪筆記、不改團隊版本。使用者仍能用文件樹直接讀寫舊日記。

**宿主與插件。** 宿主只載入隨應用發佈的清單，按 Space 配置決定可執行的命令。插件宣告名稱、側欄動作、設置和可選的啟動條件；日記命令透過當前 Space 的讀取、新建（只在不存在時）及打開頁面接口工作。啟動只在本機偏好開啟、配置已讀取、沒有深連結時觸發一次。讀取錯誤不當作空頁覆寫；切換 Space 後舊操作不跳轉到錯誤的 Space。

**相容性。** 不遷移任務、閃卡、Excalidraw。任務原有的「加入今天」可沿用日期頁文件助手，無須啟動日記插件。設置寫回保留不能辨識的鍵；本機偏好不寫入 Space。不執行筆記庫内的第三方程式碼，不做市場，也不新增日曆或日記導航。

**驗收。** 以另一個測試插件驗證宿主並非只認日記；再驗證日記開關、首次建立／重開、模板、深連結、啟動與跨 Space。跑現有前端測試、型別檢查、lint、正式建置與實際互動。原生客戶端草稿讀取性能另作獨立修復，用合成附件比對前後耗時及有無產生不應存在的 Git 物件。

參考：[Logseq 的 Journals Calendar 與命令範例](https://github.com/logseq/logseq-plugin-samples)、[AFFiNE 移除舊插件系統的變更](https://github.com/toeverything/AFFiNE/pull/5411)。採用由插件提供操作、宿主負責註冊的做法；暫不承擔第三方程式碼的信任與隔離問題。
