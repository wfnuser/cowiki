Source Directory & Dedup

Identity Hash (ingest dedup)

// Ingest-time: reject if already exists identity_hash = SHA256( source_type + source_identity ) // Examples "url" + "https://example.com/article" "pdf" + "arxiv-1706.03762.pdf" "github" + "wfnuser/cowiki" // Compile-time: semantic dedup by agent // Agent compares source content against // existing wiki pages, decides to skip or create

Example Structures

// URL article sources/sha256_abc123/ ├── manifest.json ├── content.md ├── metadata.json ├── headings.json └── attachments/ └── figure_01.png // GitHub repo sources/sha256_def456/ ├── manifest.json ├── README.md ├── issues.json └── code/

Agent explores with ls/grep/read. No fixed schema beyond manifest.json. .cowiki/state.json tracks identity hashes and source→page mappings.

Section 08

Key Design Decisions

  1. Two-stage with review gate — Team: ShallowCompile → review approve → pgvector + DeepIntegrate. Personal: immediate.
  2. Source directories — extractor builds per-source dirs with manifest.json. Identity hash (SHA of type+identity) for ingest dedup. Semantic dedup by agent at compile time.
  3. Tool separation by stage — Shallow: source FS (ls/grep/read) + wiki create only. Deep: full wiki FS (no create_wiki) + graph tools.
  4. DeepIntegrate as two serial calls — Wiki reorg first (stabilizes page_path), then graph extraction. Prevents stale fact paths.
  5. Per-space mutex — one DeepIntegrate per space. 409 if busy. Cross-space parallel.
  6. pgvector timing — Personal: immediately. Team: deferred to review approve (drafts don't pollute search).
  7. Agent pool tier-gated — Personal N=1. Team N configurable per tier (Free/Pro/Enterprise).
  8. HTTP/gRPC only — all harnesses are separate processes. No embedded mode.
  9. Git source of truth — PG derived. Eventual consistency via periodic rebuild. Orphans: 7-day grace.
  10. SSE full observability — every LLM round, tool call, entity, and fact streamed live.
